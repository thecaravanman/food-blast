# 🍕 Food Blast!

A food-themed Block Blast puzzle game — fully playable in any browser, no dependencies.

## How to play
- **Click** a food piece in the tray to select it, then **click** the board to place it
- **Drag** a piece from the tray directly onto the board (works on mobile too!)
- Fill complete rows or columns to blast them and earn points
- Clear multiple lines at once for a massive combo bonus 🔥
- Game over when none of the 3 pieces can fit anywhere on the board

## Scoring
| Action | Points |
|--------|--------|
| Place a block | 1 pt per cell |
| Clear 1 line | 160 pts |
| Clear 2 lines at once | 640 pts 🔥 |
| Clear 3 lines at once | 1440 pts 🚀 |

Your best score is saved locally in your browser.

## Tech
Pure HTML + CSS + JavaScript — zero frameworks, zero build step.  
Hosted on **Cloudflare Pages**.

## Local development
Just open `index.html` in your browser — it works with no server needed.
